# Disclaimer

ChainLink is currently in **early development**. 

While the core tool and package management features are functional, please be aware that this project is evolving rapidly. As such, some features may be unstable, incomplete, or subject to breaking changes.

## Work in Progress (WIP)

Several advanced features are still under active development, including but not limited to:
- **Roblox Model Serialization**: The mechanism for serializing and deserializing Roblox models is still a work in progress.
- **Registry Integration**: Additional registry providers and advanced authentication flows are being refined.
- **Plugin API**: The integration between the CLI and the Roblox Studio plugin is subject to change.

## Usage Warning

Because this is an early-stage project, we recommend:
- **Backing up your work**: Always maintain backups of your `chain.toml` and project source.
- **Reporting Issues**: If you encounter bugs or unexpected behavior, please open an issue on the GitHub repository.
- **Staying Updated**: Regularly pull the latest version of the binary to receive the most recent fixes and features.

We appreciate your patience and contributions as we continue to build ChainLink!
